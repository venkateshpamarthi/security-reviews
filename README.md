# Security Reviews

Independent security reviews by **[Venkatesh Pamarthi](https://github.com/venkateshpamarthi)**.

Aetherion is a personal mark on the reports — a signature, not a firm, studio, or client engagement.

This repository is a portfolio. Each review lives in its own folder with the write-up and a PDF. These are educational / independent reviews unless a folder says otherwise. They are not paid audits.

---

## How this repo is organised

```
security-reviews/
├── README.md                          ← this file
└── <Protocol>-Audit-Data/             ← one folder per review
    ├── cover.md                       ← scope, about, summary
    ├── findings.md                    ← full write-ups
    └── <Protocol>-Independent-Review.pdf
```

When I finish a review I add a new folder and a row in the table below.

## How to read a review

1. Open the folder for that protocol.
2. Start with the PDF if you want the formatted report.
3. Use `cover.md` for scope and the issue list.
4. Use `findings.md` for root cause, impact, proof of concept, and mitigation.
